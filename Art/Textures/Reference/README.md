# Reference surface asset

Tool: built-in `image_gen.imagegen`, using the gameplay reference as style input.
Saved output: `Art/Textures/Reference/sandstone.png`.
Used on real Blender mine geometry; embedded into exported GLB assets.

## Prompt

Use case: stylized-concept. Asset type: seamless tileable 3D game diffuse texture, square image. Create an orthographic top-down ochre sandstone mine-floor texture matching the warm detailed stylized 3D adventure mine in the reference image. ONLY the stone surface, no perspective, no objects, rails, coins, people, crystals, UI or cast shadows. Large irregular worn sandstone plates with subtle chipping, hairline cracks, dusty crevices, finely painted granular surface variation and restrained edge highlights. Broad flat walkable areas. Golden ochre and tan palette, medium brightness, no dramatic lighting baked in. All four borders must tile seamlessly. High-quality detailed material, avoid uniform grids and repeated geometric patterns. The supplied image is a STYLE REFERENCE, not an edit target.
