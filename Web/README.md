# DrillDrop — Яндекс Игры

## Сборка

Веб-версия собирается отдельно через Godot 4.3 с `thread_support=false` и Compatibility/WebGL 2. Основной проект и нативные сборки остаются на Godot 4.2.2. Изолированная копия и инструменты находятся в игнорируемом Git каталоге `Builds`.

Требования к инструменту загрузки: Python 3 и пакет `certifi` (`python3 -m pip install certifi`).

1. `python3 Tools/download_web_toolchain.py` — официальный macOS-редактор 4.3 и веб-шаблон.
2. `python3 Tools/build_yandex.py` — импорт ресурсов, экспорт, ZIP и проверка лимита 100 МБ до сжатия.
3. Результат: `Builds/DrillDrop-Yandex.zip`, внутри `index.html` в корне.

## Подключено

- `/sdk.js`, `YaGames.init()` до запуска движка.
- Язык RU/EN из `ysdk.environment.i18n.lang`.
- `LoadingAPI.ready()` после отображения первого экрана; `GameplayAPI.start/stop` по состоянию забега.
- Пауза и отключение звука при событиях платформы, потере фокуса и скрытии вкладки. После возврата игрок продолжает забег кнопкой паузы.
- Локальные сохранения через браузерное хранилище и штатный `user://`; облачная синхронизация между устройствами не подключена.
- Сенсорное и клавиатурное управление, защита от прокрутки/контекстного меню.
- Превью на localhost может работать без SDK. На платформе ошибка SDK отображается, а не маскируется тестовой заглушкой. Заглушки не включены в ZIP.

## Загрузка

Создайте игру или откройте её черновик в https://games.yandex.ru/console/ . Загрузите ZIP в поле «Архив», укажите русский и английский языки, управление свайпами/касаниями и клавиатурой, портретную ориентацию. Протестируйте черновик с debug-панелью Яндекса, включая готовность игры, паузы и звук. Затем заполните описание, иконку и скриншоты и отправьте на модерацию.

Реклама по кнопкам, покупки за реальные деньги и облачные сохранения не заявлены. Публикация и прохождение модерации не выполняются локальной сборкой.
