# Проверка DrillDrop — 16 сентября 2026

Среда: macOS / Apple M2, Godot 4.2.2, Blender 5.2.2.

## Выполнено

- Импорт восьми GLB, материалов и семи клипов: idle, run, lane, jump, land, slide, hit.
- Фактический запуск основной сцены в Godot с OpenGL Compatibility.
- Автотесты: три полосы; прыжок и приземление; подкат; правила столкновений для трёх типов препятствий; контакт с вагонеткой через движущуюся трассу; начисление монет; щит; притягивание монеты с соседней полосы магнитом; поражение; пять перезапусков; заморозка симуляции на паузе; продолжение; сохранение громкости; события клавиатуры и сенсорного свайпа.
- 108 000 шагов (30 минут игрового времени) на максимальной скорости: свободная полоса проверяется у каждого активного ряда. Число узлов 824 → 824. Накопления игровых объектов нет; это проверка пула, не профилирование всех выделений памяти драйвера.
- Рендер на 600 кадрах: среднее 102,16 кадра/с, 5,873 с, Apple M2. Короткий локальный замер, не гарантия для других устройств.
- Кадры меню, игры, паузы, результата и узкого экрана обучения сохранены рядом с этим отчётом. Исправлены обнаруженные белые материалы, положение кнопки паузы и масштаб интерфейса.
- macOS и Windows x64 экспортированы. macOS standalone действительно запускается с графическим рендером. Весь набор механических тестов также выполнен против упакованных ресурсов приложения: 0 failures, 824 → 824 узла. Для совместимости со старым macOS-шаблоном Godot имя пакета оставлено ASCII: DrillDrop.app.

## Ограничения

- Физический телефон, реальная работа пальцами и Windows-сборка здесь не проверялись. Свайпы проверены синтетическими событиями Godot.
- Системная UI-автоматизация недоступна (нет разрешения Computer Use). Визуальная проверка выполнена по кадрам, сохранённым самим движком; клавиши проверены программно.
- macOS-пакет имеет ad-hoc подпись, без Apple notarization; Windows exe без коммерческой подписи.
- У release-шаблона Godot 4.2.2 при завершении появляются предупреждения ObjectDB/Resources still in use. Это воспроизводится и с `--quit-after`, и после успешного набора тестов standalone. В тестах через редакторный бинарник предупреждений нет; запуск и проверки механики проходят. Для обычного закрытия окна добавлена остановка аудио перед выходом, но устранение предупреждений release-шаблона не подтверждено.
- Godot 4.2.2 при импорте рига выдаёт предупреждения об owner для дочерних skinned meshes; модели и все анимации загружаются и отображаются. Ошибок игрового скрипта нет.
- Визуал намеренно простой и низкополигональный; концепты подробнее готовых моделей. Музыка — короткая оригинальная синтезированная петля. Растровая палитра служит справочником: игровые поверхности используют PBR-цвета без внешних текстур.
