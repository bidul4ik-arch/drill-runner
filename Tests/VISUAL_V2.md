## Честные границы результата

Референсы задают направление; текущие модели всё ещё проще по анатомии, скульптуре лица, складкам одежды и художественной детализации поверхностей. Это не точное воспроизведение качества изображений.

Windows и сенсорное устройство здесь не запускались. В Godot 4.2.2 остаются предупреждения owner при импорте skinned meshes и нерегулярные ObjectDB/Resources still in use при завершении тестов. Они не приводят к сбою механики; стабильность проверена по числу игровых узлов, не по всем выделениям памяти драйвера. Сборки не имеют коммерческой подписи/нотаризации.

Финальные сборки: `Builds/DrillDrop.zip`, распакованное `Builds/macOS/DrillDrop.app`, `Builds/Windows/DrillDrop.exe`. macOS-пакет запускает OpenGL на Apple M2; при принудительном `--quit-after` завершается кодом 1 с утечкой AudioStreamPlaybackWAV/AudioStreamWAV для music.wav (подтверждено verbose-логом). Это оставшееся ограничение завершения, а не ошибка загрузки моделей. Исправление этого предупреждения не заявляется.
