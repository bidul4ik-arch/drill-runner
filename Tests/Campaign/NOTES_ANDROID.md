# Мобильная сборка

Android export preset подготовлен, но попытка экспорта через установленный Godot 4.2.2 завершилась ошибкой конфигурации, APK не создан.

Локально обнаружены Android SDK platform 34 / build-tools 34.0.0. В настройках Godot указан Temurin 17 **JRE** (без jarsigner/javac), а не полный JDK. Для Godot 4.2 официальная инструкция указывает полный OpenJDK 17, Android platform 33 и build-tools 33.0.2. Эти зависимости не устанавливались и соглашения SDK не принимались. Настройки глобального редактора не изменялись.

Есть JBR внутри Android Studio, но миграция глобального Java SDK и установка отсутствующих компонентов требуют отдельной настройки среды. Debug keystore в экспортном профиле — стандартный локальный отладочный ключ Android; для другого компьютера нужно задать свой путь. Платежи выключены, интернет-разрешение не запрашивается, вибрация включена в разрешениях и отключается в настройках игры.

Для iOS нужны Team ID, bundle identifier, signing/provisioning, физическое устройство либо симулятор и настройка Xcode. Подписанная iOS-сборка не подготовлена.

[Требования Godot 4.2 для Android](https://docs.godotengine.org/en/4.2/tutorials/export/exporting_for_android.html)
